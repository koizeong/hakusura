# ハクスラCOOP RPG 企画書

2026年10月22日 時点

## コンセプトと決定事項

放置で集めた手札から「僕が考えた最強ビルド」を組み、仲間とリアルタイムで高難度ボスに挑む、見下ろし型のハクスラCOOP RPG。

| 項目 | 決定 |
| --- | --- |
| 視点 | 2D見下ろし型(ディアブロ系) |
| 戦闘 | 作戦に従って自動で戦うオート戦闘。プレイヤーは移動で弾を避け、切り札を切る(ゆるい弾幕) |
| COOP | リアルタイム、2〜4人想定 |
| プラットフォーム | ブラウザ(PC・スマホ) |
| 開発 | Claude Code |

プレイの軸は「偶然の組み合わせのひらめき」と「それが通用したときの達成感」。一見なぜあるのか分からないスキル同士が噛み合って高火力が出る瞬間を、何度も味わえるようにする。

設計の大原則は「放置は幅、ビルドは深さ」。放置で増えるのは選択肢であり、高難度を越えられるかは組み合わせで決まる。

### 世界観

荒廃し切った、退廃的で閉鎖的な世界。誰もが死を待つばかりの鬱屈した空気が漂う。参考はKenshiやソウル系。

- 剣・魔法・銃が混在し、どれも等しく粗末で、等しく致命的
- 希望を語らない。救済よりも「今日を生き延びた」ことが報酬になるトーン
- 色は灰・錆・褪せた赤を基調にし、派手な属性エフェクトだけが暗い画面で際立つ
- 世界観とシステムを結びつける:腐敗・呪い・飢え・灰といった状態を、そのままビルドの部品として使う

## コアループ

放置で手札を増やし、厳選してビルドを組み、自分の操作で高難度ボスに挑む。この4段階を回し続ける。

```
1. 放置 ──(手札が増える)──▶ 2. 厳選とビルド
                                 │ 挑戦 ▲ 敗北で組み替え
                                 ▼      │
4. 報酬 ◀──(勝利)──────────── 3. 高難度戦闘
   └──▶ 次の放置へ
```

敗北したら放置に戻らず、すぐビルドを組み替えて再挑戦できる。この小さなループが「最強ビルド」を考える時間になる。

## ビルドシステム

ビルドの組み合わせは、タグ・トリガー・変換・ユニークの4層を掛け合わせて生む。数値の大小ではなく、組み合わせ方で強さが変わる作りにする。

| 層 | 役割 | 例 |
| --- | --- | --- |
| タグ | スキル・装備の性質を表すラベル | 火、雷、投射、範囲、召喚、近接、持続 |
| トリガー | 条件で別の効果を自動発動 | クリティカル時に雷撃、被弾時に氷の盾 |
| 変換 | ある性質を別の性質として扱う | 火ダメージの50%を雷に変換、召喚物が投射扱い |
| ユニーク | ルールそのものを壊す装備 | 回避不可だが被ダメ半減、スキル枠1つで全タグ発動 |

- タグを参照する補正は「〇〇タグのスキル+X%」の形に統一し、新スキル追加時に既存の装備が自動で絡むようにする
- トリガーの連鎖には上限(例:1回の発動から3段まで)を設け、無限ループを防ぐ
- ビルドを保存・共有できるコード形式を用意し、「最強ビルド」の見せ合いをしやすくする

### ビルド枠の構成(暫定)

1つのビルドは、スキル15枠(パッシブ専用6+兼用9)と装備9枠で組む。兼用枠をアクティブとパッシブにどう配分するかも、ビルドの選択肢になる。

| 枠 | 数 | 中身 |
| --- | --- | --- |
| パッシブ専用 | 6 | 常時効果、またはトリガーで自動発動する効果 |
| 兼用 | 9 | アクティブ・パッシブのどちらでも入れられる |
| 防具 | 4 | 頭、体、手、足 |
| 装飾品 | 3 | 装飾品1〜3 |
| 武器 | 2 | 1つ装備で両手持ち、2つ装備で二刀流 |
| 切り札 | 1 | 長いクールダウンの手動スキル |

- **両手持ちと二刀流:**どちらの持ち方かもタグとして扱い、「両手持ちのとき」「二刀流で左右の属性が違うとき」などを条件にできる。持ち方ごとの補正は試作では仮に、両手持ちが近攻撃+25%、二刀流がクールダウン-15%。スキルにも「二刀流向け」のタグを付けられる
- **アクティブの数:**アクティブは最大6個(暫定)。兼用枠の残り3つ以上は必ずパッシブになるため、パッシブは最低9個、最大15個になる。上限の数は試作で作戦の行数とあわせて確かめる

### 武器とスキルの棲み分け

攻撃の速さ・範囲・近接か遠距離か・属性は**武器**が持ち、アクティブスキルは武器をどう使うかの**技**にする。同じ技でも、持つ武器で中身が変わる。

| 持ち主 | 持つもの | 例 |
| --- | --- | --- |
| 武器 | 近接/遠距離、属性、威力、攻撃の間隔、振りかぶり、射程、扇の角度(弾なら弾速) | 鉄の剣:近接・斬・威力38・間隔0.85秒・射程100・扇130° |
| 技 | 使える武器の条件、武器の数値に掛ける倍率、形(振る・撃つ・周りに放つ) | 薙ぎ払い:近接の武器で、扇180°・威力0.9倍・間隔1.3倍 |

- **条件:**「近接の武器」「遠距離の武器」「雷の武器」「斬の近接の武器」のように、武器の種類と属性で決める。合う武器がなければその技は出ない
- **どの武器で出すか:**条件に合う武器で出す。二刀流で両手とも合うなら左右交互に出す。武器がなければ素手で出す
- **名前:**内訳では「鉄の剣の薙ぎ払い」のように、武器と技を合わせて呼ぶ。同じ技でも武器ごとに効き方が見える
- 付与(塗油)・切り札・敵のスキルは、技ではなく自分で数値を持つ
- 近接の武器は遠距離の武器より火力を高くする(DPSで1.6倍以上)

#### 武器の形・属性・性質(自動生成)

武器は「形」と「属性」と「性質」を分けて持ち、拾うたびに組み合わせが変わる。同じ槍でも「重い雷の槍」「研がれた熾火の槍」は別の物になる。

- **形:**剣・大剣・連枷・戦斧・槍・短剣・戦槌・短銃・投石紐・短弓・杖。速さ・範囲・近接か遠距離かを持つ。戦槌は当てると昏倒が溜まり、杖の魔弾は当たると弾けて周りにも当たる
- **属性:**斬・火・雷。形のもとの属性のことも、違う属性のこともある。火は信仰、雷は理力を求める。雷の剣なら雷の技も出せる
- **性質:**0〜2個。重い・軽い・長い・研がれた・粗い・幅広の・錆びた・手に馴染む・餓えた。得と損が釣り合うように傾ける
- 近接が遠距離の1.6倍以上のDPSという決まりは、全ての形と属性の組み合わせで確かめる

#### 盾

武器の枠に着ける、新しい種類の装備。直撃を1回だけ防いで砕け、時間で張り直す。

- 木の盾(10秒)・大盾(16秒、被ダメージ-10%・移動速度-10%)・祈りの小盾(弾だけ、6秒)・棘の盾(12秒、砕けると斬で弾ける)
- 属性つきの盾は砕けるとその属性で周りに弾ける。「雷の木の盾」は、殴られるたびに周りを痺れさせる
- 武器1つと盾で持ち方は「片手と盾」。盾が張られている間に効く条件文(201)や、砕けたときのパッシブ(砕けた盾の怒り)、技の変化(盾越しの)がある

#### 技の変化(自動生成)

技そのものは手作りし、遠征で拾う技に**変化**がランダムに1〜2個刻まれる。「雨垂れの薙ぎ払い」「重い三度目の斬りつけ」のような、変化つきの技になる。

- **振る舞いが変わるものを中心に:**数値の上下より、「当てると濡れが溜まる」「3回目ごとに雷が落ちる」「出血している相手には2回当たる」「空振りしたら次が強くなる」「雨の間は間隔が縮む」のように、別の部品と噛み合う変化を多くする。数値の変化(重い・速い・長い)や形の変化(大振りの・割れた)もある
- **コスト:**変化ごとに重さがあり、合計は50まで。超えたら代償の変化(鈍った・遅い・短い)を足して収める。代償は名前に出さない
- **外れ値は作り直す:**作った変化つきの技は、元の技と並べて晴れと雨の中で早回しし、元の2倍より強く出たら作り直す
- **入手と共有:**遠征で見つかる(行き先ごとに付きやすい変化がある)。元の技を覚えていなければ一緒に覚える。拾った物は全キャラで共有し、ビルドで技の型として差し替える。ビルドコードにも乗り、読み込むと蓄えに入る
- 変化は `core/src/data/variations.ts` に1件足すだけで増やせる

#### 能力値による条件

武器と技は、必要な能力値(筋力・技量・理力・信仰)を持つ。重い武器ほど筋力、細い武器や突き・連射ほど技量、雷の技は理力、火の技や塗油は信仰を求める。

- **足りなくても使える:**足りない1点ごとに威力-8%・攻撃の間隔+4%。武器と技の両方で足りなければ合わせて数える。低い能力値で無理に重い武器を振るビルドも作れる
- **基礎値として効く:**能力値そのものがキャラの強さになる。筋力は近攻撃、技量は攻撃の間隔、理力は雷、信仰は火、体力は最大HPを上げる。あくまで基礎値なので、1点の効き目は小さく(筋力1点で近攻撃+1.2%など)、全てを1つに振ってもビルドの方がずっと大きく効く
- **レベルで増える:**レベルは50が上限。Lv1で3点、1レベル上がるごとに1点増え、Lv50で52点。経験値は遠征で得る
- **振り直しはできない:**振った点は戻せず、振り方がそのキャラの個性になる。違う振り方を試すなら、キャラを増やす
- 重量・残弾・正気度は振り分ける値ではなく、戦闘中に変わる値として後で入れる

### 作戦をコンボに生かす

作戦を練ることがそのままコンボを狙うことになるよう、3つを重ねる。

- **条件を広げる:**状態・天候・床・スキルから作戦の条件を自動で作る。「相手の感電が7割以上(まだ発動前)」で仕上げ、「相手が油まみれでない」で下ごしらえ、「直前に〇〇を使った」「自分が凍った床の上」なども書ける
- **連携と型:**作戦の1行に「次に〇〇」を2つまで足せる。出したら次の一手を待って出す。決まった順(雷雨の型:濡らす→雷、凍て砕きの型:氷→打、燠火纏いの型:付与→近攻撃→近攻撃など10種)で出すと型が決まり、最後の一手が強くなる。型の書は遠征で見つかる
- **昂り:**コンボのヒットと型で溜まる。直近と同じコンボほど溜まりにくく、違う組み合わせを混ぜるほど早く満ちる。満ちると切り札が10秒早く戻り、続く3撃が+50%

### 操作方式

スキルは「作戦」に従って自動で出る。プレイヤーの指は移動と切り札に使い、スマホのブラウザでも片手でぽちぽち遊べるようにする。敵の弾は遅く読みやすい「ゆるい弾幕」にして、移動で避ける楽しさを残す。

| 操作 | スマホ | PC |
| --- | --- | --- |
| 移動 | 押して引く(浮きスティック)、地面をタップでそこへ歩く | W A S D、マウスでも同じ |
| 狙う相手の指定 | 敵をタップ(もう一度で外す) | 同じ |
| 切り札 | 右下のボタン | Space |
| 早送り | 右上のボタン(×1〜×3) | 同じ |
| ダメージ内訳 | 右上の「勘定」 | Tab |

- **作戦:**「〈条件〉なら〈スキル〉」の行を並べ、上から順に見て、条件に合い使えるものを1つ使う。届かなければ寄っていく。条件は条件文と同じ部品(状態・天候・付与・強化など)で書き、ビルドの一部として組む
- **移動はすいすい:**攻撃中も足は止まらない。当たり判定は見た目より小さくし、弾の間を抜けられるようにする
- **切り札:**ビルドに1つ入れる、長いクールダウンの手動スキル。天候を変える・床を敷く・周りを一斉に感電させる、のように組み合わせの起点になるものを揃える。押すと予約され、硬直が明けしだい・届きしだい出る
- **近攻撃のほうが火力が出る:**遠攻撃は弾を避けながら撃てて楽なので、同じ手間なら近攻撃が勝つようにする(DPSで1.6倍以上を目安)。近攻撃は振った範囲の敵の弾をかき消す
- **見切り・弾き:**ジャスト回避・ジャストガードの入力は置かず、確率で自動に見切る・弾くパッシブとしてビルドに入れる
- キーは全て変更できるようにする
- 武器の持ち方は装備で決まるため、戦闘中の持ち替えは置かない
- 手動で全スキルを撃つ操作(左右クリック・Q/E/R/F)は、比べるために試し斬り場に残している

スキルはアクティブ・パッシブそれぞれに、次の6分類を持つ。

| 分類 | アクティブの例 | パッシブの例 |
| --- | --- | --- |
| 近攻撃 | 錆びた大剣で薙ぎ払う | 出血中の敵への近接ダメージ増加 |
| 遠攻撃 | 散弾銃を撃つ、灰の矢を放つ | 残弾が少ないほど銃の威力が上がる |
| 付与 | 武器に腐敗を纏わせる | 炎上した敵に触れると毒も付与 |
| 召喚 | 死体から亡者を起こす | 召喚物が死ぬと周囲に瘴気が出る |
| 防御 | 灰の盾を張る | 瀕死のとき被ダメージを軽減 |
| 回復 | 血を啜って回復する | 正気度が下がるほど自然回復が増える |

分類も1つのタグとして扱い、「付与スキルを使った直後の召喚」のように分類同士を条件にできるようにする。

### 組み合わせの部品

ひらめきの種を増やすため、状態・属性・パラメータ・フィールドの種類はなるべく多く揃える。どの部品も、他の部品の条件として参照できるようにする。

| 部品 | 内容 |
| --- | --- |
| 属性 | 11種(下の一覧) |
| 状態 | 23種(下の一覧) |
| パラメータ | 筋力、技量、理力、信仰、体力、重量、残弾、正気度 |
| フィールドの環境 | 雨、砂嵐、霧、夜、瘴気、無風 |
| フィールドの状態 | 油溜まり、血だまり、水たまり、灰の堆積、死体、燃え跡、凍った床 |

組み合わせの例:雨で敵が濡れる → 感電の効果が倍 → 「感電した敵が死ぬと周囲に水たまりができる」スキルで連鎖させる。

#### 試作での天候と床

| 天候 | 効き方 |
| --- | --- |
| 雨 | 全員が濡れる |
| 砂嵐 | 盲目が溜まり、移動速度-10%。弾の届く距離0.65倍 |
| 霧 | 弾の届く距離0.55倍。背後からの奇襲+30%。画面は自分の周りしか見えない |
| 夜 | 闇+40%・呪+20%。画面は自分の周りしか見えない |
| 瘴気 | 全員に腐敗が溜まり、回復-30% |
| 無風 | 炎上が1.5倍長く燃え、感電は遠くまで飛ばない |

| 床 | できるとき | 効き方 |
| --- | --- | --- |
| 油溜まり | 油壺・油袋 | 油まみれが溜まる。上で炎上すると燃え跡になる |
| 血だまり | 出血したとき | 渇きが溜まる |
| 水たまり | 凍結が解けたとき、水差し | 濡れる。上で凍結すると凍った床になる |
| 灰の堆積 | 灰化で崩れたとき | 灰化が溜まる |
| 死体 | 倒れたとき(灰になった者は残らない) | 腐敗が溜まる |
| 燃え跡 | 炎上が終わったとき、油溜まりが燃えたとき | 炎上が溜まる |
| 凍った床 | 水たまりの上で凍結したとき | 移動速度+25%だが凍結が溜まる。上で炎上すると水たまりに戻る |

- 床は敷いた者を覚え、床で溜まった状態とそのダメージはその者の手柄になる
- 一戦「灰の街道の夜」は夜、遠征「灰の街道」は砂嵐の中で戦う
- 切り札で天候と床を呼べる:雨乞いの鈴(雨)・霧笛(霧)・灯消し(夜)・油壺(油溜まり)・水差し(水たまり)

### 属性と状態の一覧(34種)

属性11種はそれぞれ対応する状態を1つ持ち、さらに属性を持たない状態が12種ある。全ての状態は敵にも味方にもかかる。

| 属性 | 対応する状態 | 効果 | 噛み合う相手 |
| --- | --- | --- | --- |
| 斬 | 出血 | 動くたびにダメージ | 逃げ回る敵、召喚物 |
| 打 | 昏倒 | 蓄積が満タンで数秒行動不能、被ダメージ増加 | 凍結、鈍重 |
| 刺(銃弾を含む) | 露出 | 防御が下がる | 高火力の単発攻撃 |
| 火 | 炎上 | 継続ダメージ。濡れていると付かない | 油まみれ、油溜まり |
| 雷 | 感電 | 近くの敵に連鎖する | 濡れ、水たまり |
| 腐 | 腐敗 | 回復が反転してダメージになる | 回復する敵 |
| 呪 | 呪縛 | 受けたダメージの一部を解除時にまとめて受ける | 死の宣告 |
| 氷 | 凍結 | 蓄積が満タンで停止。打撃で砕くと大ダメージ | 打 |
| 闇 | 盲目 | 視界と命中が落ちる。背後からの攻撃が必ずクリティカル | 恐怖、背後攻撃 |
| 灰 | 灰化 | 蓄積で動きが鈍り、満タンで崩れる。死体が残らない | 死体ビルドへの対抗 |
| 血 | 渇き | 自分のHPを払って威力を出す。出血した相手から体力を吸う | 出血、瀕死 |

| 属性を持たない状態 | 付く条件 | 効果 |
| --- | --- | --- |
| 濡れ | 雨、水たまり | 炎上を防ぎ、感電を強める |
| 油まみれ | 油溜まり | 炎上の時間と範囲が倍 |
| 飢え | 戦闘の長期化 | 回復効果が半減 |
| 狂気 | 正気度が尽きる | 敵味方の区別なく攻撃が当たるが、火力が大幅に上がる |
| 恐怖 | スキルなど | 一定時間逃げ回り、背後攻撃の的になる |
| 瀕死 | HPが一定以下 | 「瀕死のとき」系の効果の起点 |
| 無傷 | 一度も被弾していない | 被弾した瞬間に解除 |
| 鈍重 | 装備重量の超過 | 移動が遅いが、打の威力が上がる |
| 死の宣告 | スキルなど | カウント0で即死。カウント中に倒すと周囲に呪縛を撒く |
| 加護 | 防御・回復スキル | 次の1撃を無効化 |
| 憤怒 | 被弾 | 被弾するたびに攻撃力が上がる |
| 静寂 | スキル、フィールド | アクティブスキルが使えない |

#### 試作での実装

一覧の34種は全て `core/src/data/elements.ts` と `core/src/data/statuses.ts` に入っている。企画の文から決めた細部:

- **打:**昏倒を溜める。凍結した者を打で叩くと「砕氷」で大きく効き、凍結が解ける。火を当てても凍結は解ける
- **刺:**露出(被ダメージ+30%)を溜める
- **腐:**腐敗は回復をダメージに変える。回復する相手がまだ少ないので、弱い継続ダメージも持たせた
- **呪:**呪縛の間に受けたダメージの4割を溜め、切れたときにまとめて受ける(呪いの清算)
- **氷:**凍結で動けなくなる(凍りつく瞬間に小さく効く)
- **闇:**盲目の者の攻撃は35%で外れ、盲目の者は背後からの攻撃で必ず急所に入る(与ダメージ倍)
- **灰:**溜まるほど足が鈍り(満タンで-50%)、満タンで崩れて大きく効く
- **血:**渇きは当てた側に溜まる。渇くと与ダメージ+40%だが、直撃のたびに最大HPの2%を払い、出血した相手からは与えた分の25%を吸う
- **飢え:**戦っている間に溜まり(およそ2分で満ちる)、回復が半分になる
- **狂気:**与ダメージ+80%、敵味方の区別なく当たる。正気度はまだないので、切り札「狂い水」で自ら呑まれる
- **恐怖:**スキルを使えず、背を向けて逃げる。背後から斬られやすい。技の変化「脅かす」で付く
- **瀕死・無傷:**HPが25%以下、一度も被弾していない。本人の様子で決まり、条件の起点になる
- **鈍重:**装備の重さが担える重さ(15+筋力)を超えると、移動速度-25%・打+30%
- **死の宣告:**10秒で倒れる。宣告のまま倒されると、周りの仲間に呪縛を撒く。技の変化「宣告する」で付く
- **加護:**次の直撃を1回無効にする。切り札「加護の祈り」で付く
- **憤怒:**被弾するたびに溜まり、満ちると与ダメージ+50%
- **静寂:**アクティブスキルを使えない。技の変化「黙らせる」で付く
- 武器は11の属性のどれにもなる。連枷と戦槌のもとの属性は打、短剣と短弓は刺。錆鎧は打と雷に弱い

### 補正値のルール(暫定)

装備とパッシブスキルには補正値が付く。1つあたりの補正値の合計を-100%〜+100%に収めることで、どの装備も「総量はほぼ同じで、配分が違う」状態にする。

| 項目 | ルール |
| --- | --- |
| 補正値の範囲 | 1項目あたり-200%〜+200% |
| 項目の数 | 1つの装備につき、ランダムで1〜4種類 |
| 合計の範囲 | 全項目の合計が-100%〜+100% |
| 条件文 | 項目の1枠を使って入ることがある。1つの装備に1枠まで |

- **例:**火ダメージ+180%、移動速度-120%(合計+60%)
- **条件文の例:**炎上状態であれば2回攻撃できる(候補は付録Aを参照、200個)
- **狙い:**合計に上限があるため、補正値が全部高いだけの装備は出ない。厳選は「高い数値を探す」ではなく「欲しい配分を探す」になる

決定事項

- **合計の単位:**装備1つごとに-100%〜+100%
- **共通項目:**各装備に最大HP・移動速度・被ダメージなどの共通項目が必ず入る。使わない項目へのマイナスだけで得をしないようにするため
- **条件文のコスト:**条件文にも補正値換算のコストを持たせ、合計に含める。強い条件文ほど他の項目が下がる
- **低いほど強い補正:**実装する
- **極端な値:**上限は設けず、実装してみて困ったものだけ排除する
- **アーティファクト:**ランダムな装備とは別に、効果が固定された装備を用意する(候補は付録Bを参照、200個)

### 拾い物の出方と見比べ(触ってみての見直し)

触った感想は「ビルドが複雑な割に、ゴミ装備が多く、シナジーを感じず、効果を実感しにくい」だった。最初のキャラ相当のビルドに、ランダムな装飾品150個を1つずつ着けて早回しで測ると、合計がマイナスのものが57%、DPSが±5%以内しか動かないものが56%、5%以上強くなるものは25%しかなかった。そこで次のように直した。

- **合計は得の向きに寄せる:**たいていは+20%〜+100%。12%の確率で合計がマイナスの「忌まわしき品」になり、代わりにコスト40%以上の重い条件文が必ず付く
- **1項目の振れ幅:**たいていは-40%〜+120%、1割だけ±200%まで振れる(決まりの範囲はそのまま)
- **ビルドに寄せる:**拾い物・遠征・大物の持ち帰りは、今のビルドの属性(技なら合う武器の属性)と技の種類(近攻撃・遠攻撃・付与)に6割ほど寄る(`lootFit`)。補正値も繋ぎもこれに合うものが出やすい
- **見比べ:**札ごとに「〇〇と替えると 火力+12%・耐久-5%」を早回しで測って出す。火力は案山子の群れへの毎秒の傷、耐久は最大HP÷被ダメージの倍率。着けている物には「この装備で」の寄与を出す(`core/src/loadout.ts`)
- **まとめて捨てる:**火力も耐久も上がらず点が下がる物だけを「弱くなる」とし、山から一度に捨てられる
- **おすすめで着ける:**武器の枠から順に、部位ごとに一番点の高い物を選ぶ。点は火力×耐久^0.5(耐久は3000で頭打ち)。早回しは画面と別の糸で回す
- **段階的に開く:**新しく始めたときは遠征・型・変化つきの技を伏せる。一戦を終えると遠征、初めて型が決まると型、遠征から戻るか大物から変化つきの技を得ると変化つきの技が開く。これまでの保存は全て開いたまま

直した後の同じ測り方:ビルドに寄せた拾い物では、強くなるもの58%、弱くなるもの11%。

### 繋ぎ(〇〇の次に〇〇)

組み合わせを自分で見つけ、連鎖で数字が大きくなっていくのを肝にする。条件文の一種として「〈前の手〉の次に〈今の手〉を当てると〈見返り〉」を足した(`core/src/data/links.ts`)。

- **前の手:**属性11種か、近攻撃・遠攻撃・付与。3秒以内に使ったもの。前の手はスキルを使った瞬間に決まるので、飛んでいる弾が当たるときも変わらない
- **今の手:**属性11種か、近攻撃・遠攻撃
- **見返り:**与ダメージの倍率か、威力半分のヒットを足す。属性どうしのように細かい繋ぎほど大きい(種類→種類は2倍か+3ヒット、片方が属性なら2.5倍か+4ヒット、属性→属性は3倍か+5ヒット)
- 例:「雷で攻めた次に近攻撃を当てると、与ダメージ2.5倍」「火で攻めた次に氷の攻撃を当てると、5回多く当たる(威力は半分)」
- 繋ぎは他の補正と別の種類なので乗算で重なる。A→B と B→C を持てば、作戦の連携(次に〇〇)で A→B→C と並べて数字が跳ねる
- 決まると「雷→近攻撃の繋ぎ」としてコンボの名前が出て、昂りも溜まる。勘定の条件文の行には、宿している装備の名前が付く
- 属性か種類を1件足せば、繋ぎも増える(儀式を前の手に足して、今は364個)

### 儀式(次の技に力を盛る)

攻撃だけでなく、次の技に力を盛るアクティブ。儀式を重ねてから大技で一気に使い切る「儀式を重視するビルド」を作れるようにする。

| 儀式 | 次の技に宿す力 |
| --- | --- |
| 黙祷 | 与ダメージ+60%(短く、早く戻る) |
| 研ぎの儀 | 3回多く当たる(威力は半分) |
| 血の誓い | 最大HPの8%を捧げ、与ダメージ+150% |
| 灰の祝詞 | 技を灰の属性に変え、灰化を溜める |
| 雷の印 | 当たると雷の追撃 |
| 焚き上げ | 宿している儀式1つごとに与ダメージ+50% |

- 宿した儀式は、次の攻撃の技(近攻撃・遠攻撃)で全て使い切る。儀式どうしは別の種類なので掛け合わさる(黙祷と血の誓いで×1.6×2.5)。5つまで、10秒で消える
- 作戦の条件に「儀式を〇つ以上宿している」「宿した儀式が2つ以下」を足した。手本の作戦(支度の作戦の「儀式の手本にする」)は、儀式を三つ重ねてから技で使い切る
- 三度の祈りの型(儀式・儀式・儀式・近攻撃)、条件文「儀式を3つ以上宿した技は与ダメージ2倍」「儀式のクールダウン-15%」、繋ぎ「儀式を出した次に〇〇を当てると」
- 血の誓いは自分を削るので、出血や瀕死を使うビルドとも噛み合う

### 被ダメージの下限

被ダメージの倍率は0.3より下がらない(どれだけ積んでも7割減まで)。被ダメージ-200%の装備を重ねると傷を受けなくなっていたため。極端な値に上限を設けない原則の例外として、困ったものを後から排除した最初の1件

### 変わった条件の効果

補正値が高いだけの装備を延々と厳選させないため、数値の大きさ以外を条件にする効果を多く用意する。

- 装備の補正値の**合計がちょうど〇〇**のとき発動
- 補正値が**低いほど**効果が上がる(最低品質の装備に価値が生まれる)
- パラメータが**偶数/奇数**のとき
- 最も**低い**パラメータの値に比例してダメージが増える
- 装備の**重量が0**、または**所持品が満杯**のとき
- **正気度が低いほど**火力が上がり、被ダメも増える
- 周囲の**死体の数**に応じて効果が変わる
- 直前に**別の属性**で攻撃したときだけ発動(属性を交互に使わせる)

### ビルドが一辺倒にならないための調整

「物理だけに振るのが結局強い」を防ぐため、単一の方向に特化するほど伸びが鈍る仕組みと、混ぜるほど得をする仕組みを両方入れる。

- **同種の補正は加算、異種の補正は乗算:**同じ「物理+%」を重ねても伸びは緩やか。違う種類を掛け合わせると大きく伸びる
- **敵の耐性を分散させる:**どの属性にも強い敵と弱い敵がいて、単一属性では詰まる場面を作る
- **隠れた最適解を探すシミュレーター:**戦闘ロジックを分離しておき、全組み合わせを自動で戦わせて、突出したビルドや使われない部品を開発中に洗い出す
- **上方修正を基本にする:**強すぎるビルドを弱めるより、使われない部品を強くして釣り合わせる。見つけた「最強ビルド」が消える失望を避けるため

## 遠征隊(放置)

放置の形は遠征隊にする。キャラを行き先に送り出すと、帰ってきたときに経験値・装備・新しいスキルを持ち帰る。遠征中のキャラは戦えないので、キャラを何人も作って回す。

| 行き先(試作) | 時間 | 手強さ | 環境 | 出やすい物 |
| --- | --- | --- | --- | --- |
| 野営地の見回り | 2分 | 60 | なし | 少し |
| 灰の街道 | 30分 | 120 | 敵は雷に強い | 斬・出血・移動の物、出血や駆ける刃の条件文 |
| 錆の廃坑 | 2時間 | 220 | 油溜まりの床、敵は火に強い | 武器(大剣・斧・連枷・投石紐)、火と炎上の物 |
| 沈んだ聖堂 | 8時間 | 400 | 雨、敵は斬に強い | 雷・感電の物、条件文つきの装備、雷と雨の技 |

- **ビルドで持ち帰る量が変わる:**帰還したとき、そのキャラのビルドで、その地の環境(雨・床・敵の耐性)のまま案山子の群れと短く戦わせ(早回し)、DPSを測る。行き先の手強さより強いほど多く持ち帰る(0.3〜1.5倍)。行き先ごとにビルドを考える理由になる
- **負傷:**測った強さが手強さの70%に満たないと、負傷して戻ることがある(足りないほど起きやすく、最大80%)。負傷の間(遠征の時間の半分、最短5分)は戦えず、遠征にも出せない
- **経験値:**長い遠征ほど時間あたりの経験値が多い。Lv50までは、聖堂へ手強さどおりの強さで通って60時間ほど(試作の値)
- **スキルは遠征で覚える:**覚えたスキルはアカウント全体で共有し、どのキャラでも使える。最初は基本の技・塗油・パッシブ4つ・雨乞いの鈴だけ覚えている
- **装備は拾い物の山へ:**持ち帰った装備は全キャラで共有する
- 同じ遠征なら同じ物を持ち帰る(出たときの乱数の種で決まる)

## 試行錯誤を軽くする仕組み

ひらめいたらすぐ試せるように、組み替えと別キャラの作成はほぼ無料・ワンタッチにする。集めた部品はアカウント全体で共有する。

- **組み替え無料:**装備・スキル・作戦・切り札の付け替えにコストをかけない
- **能力値はキャラの個性:**能力値は放置で育ち、振り直しはできない。別の振り方を試すときは、キャラを気軽に増やす
- **1キャラ1ビルド:**ビルドの切り替えはキャラの切り替えで行う(プリセットは置かない)
- **部品の共有:**集めたスキルと装備は全キャラで使える。新キャラも、すぐ既存の部品で組める
- **試し斬り場:**天候・床の状態・敵の状態・耐性を自由に設定できる案山子を置き、実戦前に組み合わせを確かめられる
- **ビルドコード:**文字列で書き出し・読み込みでき、仲間と見せ合える

### 与ダメージの表示

「何が効いたのか」が分からないと、ひらめきが再現できない。表示は気持ちよさと分析の2段にする。

- **戦闘中:**ヒットごとの数値を属性の色で表示。連鎖や条件が発動したヒットは大きく、発動したスキル名を添える
- **コンボ:**相互作用・条件文・連鎖が噛み合ったヒットは「雷雨」「血雷」のようなコンボとして名前を出し、続いた数(〇連)も出す。コンボの種類はデータで足せる
- **戦闘後:**スキル・属性・条件ごとのダメージ内訳とDPSを表で出す。「全体の何%がどの連鎖から出たか」が分かるようにする
- **COOP:**仲間ごとの内訳と、シナジーで上乗せされた分を分けて表示する

## 敵・ボス設計

高難度の敵は「ビルドへの問い」として作り、1つのビルドで全部に勝てないようにする。腕前だけで突破できる敵ばかりだと、ビルドの価値が下がるため。

### 雑魚の試作(5種)

雑魚もそれぞれ別の問いを持たせる。1回の戦闘(一戦)はおよそ3分半で(どの一戦もこの長さに揃える)、決まった時刻に群れが来る。場を片付ければ次の群れは3秒で来るので、強いビルドほど早く終わる。

| 敵 | 型 | 振る舞い | ビルドへの問い |
| --- | --- | --- | --- |
| 屍喰い | 群れ | 脆く速い。囲むように散って寄り、噛んで出血を刻む | 範囲の技があるか。囲まれない足運び |
| 煤吹き | 射手 | 間合いを取り、寄られると下がる。横歩きで弾を外させる。火に強い | 追い詰める足か、当て続ける手段があるか |
| 錆鎧 | 鎧 | 遅く硬い。斬と火に強く雷に弱い。長い予兆のあと重く叩く | 属性の選び。避けてから叩く間合い |
| 油袋 | 床 | 足元に油を吐く。倒れると火を噴いて弾け、油溜まりを残す。破裂は敵味方なく当たる | 床と燃焼を使えるか。巻き込める位置で倒せるか |
| 鐘守 | 場を変える | 仲間の陰から雨を呼び、雷の輪を撒く。雨は火を消し、濡れた者の感電を倍にする | 先に倒すか、雨を自分の雷に使うか。狙う相手の指定 |

さらに9種を足した。

| 敵 | 型 | 振る舞い | ビルドへの問い |
| --- | --- | --- | --- |
| 屍術師 | 死体 | 間合いを取り、近くの死体を屍喰いとして起こす | 死体を残さない灰で崩すか、先に術師を倒すか |
| 棘の亡者 | 棘 | 近攻撃を受けると35%を返す。刺に強く火に弱い | 遠くから崩すか、返されても押し切るか |
| 霜の巫女 | 足場 | 相手の足元を凍った床に変え、霜の輪を撒く。火に弱い | 火で解かすか、凍った床の滑りを使うか |
| 影潜み | 背後 | 間合いを取り、影を渡って背後から闇の刃で斬る | 盾で受けるか、振り向いて迎えるか |
| 疫病の運び手 | 癒し手 | 仲間の陰で傷ついた仲間を癒し、瘴気を呼ぶ | 腐らせて癒しを傷に変えるか、先に倒すか |
| 宣告者 | 時間切れ | 遠くから宣告の矢で死の宣告を溜める | 満ちる前に倒すか、加護で防ぐか |
| 血の狂信者 | 吸血 | 跳びかかり、血で裂く。出血した相手から吸う | 出血を止めるか、一気に倒すか |
| 巣袋 | 巣 | 動かずに屍喰いを産み続ける(4体まで)。火に弱い | 真っ先に潰せるか。届く手段があるか |
| 黙りの修道士 | 封じ | 仲間の陰から沈黙の輪を撒き、静寂を溜める | 切り札で凌ぐか、弾を避け切るか |

- 一戦を2つ足した。霧の墓守り(霧、屍術師・影潜み・棘の亡者・巣袋)と疫病の行軍(無風、疫病の運び手・宣告者・血の狂信者・黙りの修道士・霜の巫女)
- 静寂と恐怖の間も、切り札だけは使える
- 敵は `core/src/data/enemies.ts` に1件足すだけで増やせる。動き方(寄る・囲む・間合いを取る・仲間の陰に立つ)、スキル、耐性、倒れたときの効果を持つ
- 一戦は `core/src/data/encounters.ts`。最初の一戦「灰の街道の夜」は10の群れ・44体

### 大物の試作:灰翼の飛竜

1匹で現れ、体力が多く、図体が大きく、攻めが苛烈で、討てば多くを持ち帰る大物。一戦「灰翼の巣」で一対一に戦う(3分半)。

| 項目 | 決めたこと |
| --- | --- |
| 体 | 体力30000(雑魚で一番硬い錆鎧の20倍)、半径46、80×80の絵。耐性は火・灰に強く、氷と雷に弱い |
| 地上の攻め | 飛竜の顎(前を噛む)、尾の薙ぎ払い(寄った者を周りごと)、灰炎の息(長く溜めて前へ太い炎を3段。濡れていれば燃えない) |
| 飛翔 | 現れて24秒後から、42秒ごとに11秒飛ぶ。飛んでいる間は近攻撃と周りに放つ技が届かず、床も踏まない。火の雨(回る輪)と火の礫(扇)を撒く |
| 急降下 | 飛ぶ時間が切れると、一番近い相手を狙って急降下する。狙った所は振りかぶりの時に決まるので、印を見て離れれば避けられる。降りた周りを砕き、地に降りる |
| 逆鱗 | 体力が3割を割ると怒る。技の間隔が0.65倍、歩みが1.3倍 |
| 踏ん張り | 昏倒・凍結は0.3倍しか溜まらない(止めっぱなしにできない)。ほかの状態は普通に溜まる |
| 持ち帰り | 討てば装備6つ(条件文が6割で付く。火・灰・遠攻撃・被ダメージの物が出やすい)、経験値1500、変化つきの技1つ、まだ覚えていないスキル(6割)と型の書(5割)。時間切れで去られたら、その1/4 |

- ビルドへの問い:飛ばれたときの遠攻撃の備え、炎の息を雨(濡れ)で鈍らせる知恵、急降下の印を見て離れる足
- 早回しの目安:最初のキャラ(剣と短銃)が足を止めて殴り続けると110〜150秒で討てる。避けながらなら手数が落ちて、3分半に近づく
- データでは `EnemyDef` の `boss`・`poise`・`enrage`・`approach`、技の `aloft`(飛んでいる間だけ/地にいる間だけ)と `opening`(現れてから最初に使えるまで)、行動の `takeOff`(`land` で降りる技)と `blink` の `where: 'at'`・`land`。一戦の `boss` と `reward`

| ギミック | ビルドへの問い | 苦戦するビルド |
| --- | --- | --- |
| 被弾ごとに攻撃力が上がる | 少ない手数で大ダメージを出せるか | 多段ヒット・持続ダメージ |
| 状態異常無効 | 変換や素の火力で対応できるか | 状態異常依存 |
| 召喚物を優先して狙う | 本体の火力と耐久があるか | 召喚 |
| 避けきれない全体攻撃 | 耐久をビルドで用意したか | ガラスキャノン |
| 一定時間内に倒さないと全滅 | 火力を十分に積んだか | 耐久特化 |

- 腕前で避けられる攻撃と、ビルドでしか受けられない攻撃を1体のボスに混ぜる
- 挑戦前にボスのギミックを開示し、ビルドの組み替えを促す

## COOP設計

2〜4人のリアルタイム協力を想定し、他のプレイヤーのタグを参照できる効果で「組んで初めて完成するビルド」を作れるようにする。

- **シナジー効果:**「味方が凍結させた敵に追撃」「味方の召喚物にも自分のバフが乗る」など、他人のタグを条件にする
- **役割:**固定職業は置かず、ビルドの結果として前衛・火力・支援が自然に分かれる形にする
- **人数による調整:**ボスの体力とギミックの数を人数に応じて増やす
- **戦利品:**ドロップは個人ごとに出し、取り合いを起こさない
- **ソロ:**ソロでも遊べるように、自分専用の調整を入れるかは未決

## 技術構成

描画はPhaser 3、通信はColyseus(Node.js)で組み、ダメージ計算は描画から切り離した共通ロジックにする。

| 部分 | 技術 | 担当 |
| --- | --- | --- |
| 描画・入力 | Phaser 3(TypeScript) | 自キャラの移動、エフェクト、UI |
| 通信 | Colyseus | 部屋の管理、状態の同期 |
| 戦闘ロジック | 共通TypeScriptモジュール | タグ・トリガー・変換を含むダメージ計算 |
| 保存 | サーバー側DB(未決) | キャラ、装備、放置の進行 |

- **同期の方針:**自キャラの移動は各画面で即座に反映し、スキルの発動(作戦)・敵の行動・ダメージ判定はサーバーが決める。タイミングの判定がシビアでないため、通信の遅れが手触りに響きにくい。協力プレイなのでチート対策は最小限でよい
- **放置と戦闘を同じ計算にする:**作戦で戦うので、入力なしでも戦闘が進む。放置の進行もシミュレーターも、同じ戦闘を早回しして求める。乱数は種つきにして再現できるようにする
- **計算の分離:**ダメージ計算は純粋な関数にして、単体テストとバランス調整用のシミュレーションを回せるようにする
- **放置の計算:**オフライン中の進行は、ログイン時に経過時間からサーバーでまとめて計算する

## グラフィックの方針(今後)

試作は図形で描いているが、没入感のために世界観に沿った絵に替える。

- **画風:**ドット絵。荒廃した退廃的なダークファンタジー(Kenshi・ソウル系)に合わせ、くすんだ色と少ない色数で描く。属性と状態の色は、今の色を印として残して読みやすさを保つ
- **要る絵:**自キャラ(持ち方・武器の形ごとの見た目)、敵14種(予兆の動きを含む)、案山子、床7種、天候6種の重ね絵、状態の印、弾と近攻撃の軌跡、装備とアイコン
- **進め方:**見下ろしの大きさと向きの数を先に決め、敵の見分けやすさ(弾幕の中で何が来たか分かるか)を確かめながら1種ずつ替える

### 決めた形式(自キャラで試した)

| 項目 | 決めたこと |
| --- | --- |
| 1コマ | 32×32。画面では2.25倍(PCで約70px、スマホで約35px)。拡大は最近傍 |
| 向き | 下・上・横の3つ。左は横を裏返す |
| 動き | 待機2・歩き4・攻撃3(振りかぶり・伸びきり・戻り)・被弾1 |
| 並び | 行が向き(下・上・横)、列が動き(待機0,1・歩き0〜3・攻撃0〜2・被弾)。1枚320×96 |
| 色 | くすんだ茶と灰の外套に、血の色の襟巻きだけを差す。縁取りは自動で1マス |
| 当たり判定 | 絵の胴(18段目)が立ち位置。当たり判定は胴の小さな点。付与と盾は足元の輪で見せる |
| 作り方 | 絵はコードで描く。同じ並びの PNG を置けば差し替わる |

- 自キャラ「巡礼者」:頭巾と擦り切れた外套、頭巾の奥の暗がりに目だけが光る。歩くと襟巻きの端がなびく
- **武器と盾:**体と別の絵。武器は32×16で右向き・握りが左、盾は16×16の正面。形ごとに1枚描き、属性は刃の縁・宝玉・弾の色に差す(斬・打・刺は鋼のまま)。1本目は利き手、2本目と盾は逆の手に持ち、上向きは体の後ろに隠れる
- **敵:**正面(斜め上から)の1向きで、左を向けば裏返す。動き0・動き1・振りかぶり・被弾の4コマ。屍喰い・煤吹き・鐘守・屍術師・霜の巫女・影潜み・疫病の運び手・宣告者・血の狂信者・黙りの修道士は32×32、錆鎧・油袋・棘の亡者・巣袋は48×48。振りかぶりの間は赤みを帯び、当たった瞬間は白く光る
- **重なり:**自キャラ・敵・案山子は立ち位置の高さ(y)で重なり順を決める。体力・状態の印・弾は絵の上に重ねる
- **地面:**戦場全体を1枚の絵(升の大きさで描き2.25倍)にする。乾いた土の濃淡に、ひび・石・枯れ草・骨。種つきの乱数で毎回同じ絵
- **床:**種類ごとに縁の揺らいだ溜まりの絵(油の虹、血と水の照り返し、灰の小山、焦げのひびと燻る点、氷のひび)。半径は4升刻みで3通りの形を使い回し、本当の半径に合わせて伸ばす。死体は横たわる体の絵。消える間際は薄れる
- **弾:**14×10 で右向きに描き、飛ぶ向きへ回す。味方は属性ごとの形(斬・刺は矢、打は礫、火は炎、雷は火花、ほかは魔弾)。敵の弾は形を丸に揃え、赤い縁と白い芯で弾幕の中でも見分ける
- **状態の印:**9×9。画面下の自分の状態の前と、発動中の状態を棒の下に横に並べる
- **装備の印:**32×32。武器は持つ絵を斜めに、盾は持つ絵を倍に。防具は部位の形に素材の色、装飾品は名前の形(指輪・数珠・護符・鈴・鏡片・徽章)、アーティファクトは眼の遺物
- **天候:**雨と砂嵐は升に揃えた粒で描く。霧と夜は自分の周りだけ見える暗がり、瘴気は淡い色と漂う粒
