# ビルドの強さの傾向(2026-10-28)

型どおりのビルド9つを、シミュレーター(`packages/core/src/sim/`、`npm run sim`)で測った。どれも Lv30・能力値32点で武器だけを持ち、防具と装飾品は、ビルドに寄せた拾い物80個から「おすすめ」で選ばせた(「揃え」)。一戦は操り手(届く間合いへ寄り、敵の弾と振りかぶりから逃げる簡単な足)つきで3回ずつ戦わせた。

## わかった傾向

1. **装備の倍率が全てを決めている。**揃えると火力が素の11〜170倍になる。ビルドの選び(武器・技・パッシブ)の差は数倍なのに、装備の差は桁が違う
   - 原因A:**違う種類の与ダメージ補正が掛け算で重なる。**与ダメージ・近攻撃・斬・火・雷・状態……が全て別の種類なので、7部位に散らばると掛け算で膨らむ。最初の巡礼者は条件文なしの補正値だけで×13.5
   - 原因B:**繋ぎが「一辺倒」のビルドで常に成立する。**「近攻撃を出した次に斬の攻撃を当てると×2.5」は、斬の近攻撃しか出さない大剣では毎回決まる。組み合わせのひらめきではなく、単色のビルドへのご褒美になっている(大剣の夜の傷の80%が「近攻撃→斬」)
   - 原因C:**ヒット追加の繋ぎが重なると爆発する。**+4ヒットを2つ持つと増えたヒットにも倍率が乗り、弓は素40→揃え2,118(×53)、大盾は×170
   - 大剣の内訳:補正値だけで×4.3、条件文(繋ぎ)だけで×7.0、両方で×31
2. **組み合わせるビルドほど損をしている。**最初の巡礼者(剣と短銃、雷雨)は揃えても×13.5で、条件文が1つも選ばれない(繋ぎが噛み合う相手が毎回変わるため)。儀式の剣士は×2.9で一番伸びない(儀式に噛む装備がない)
3. **大物が柔らかすぎる。**揃えたビルドは飛竜を6〜54秒で倒す(大剣6秒)。体力30000は素のビルドに合わせた値
4. **近接は群れの一戦を討ち尽くせない。**大剣・短剣・大盾・戦槌は夜明けまで残る(大剣は44体中36体)。間合いを取る射手・仲間の陰の支援役に追いつけない。操り手が単純なせいもあるが、遠攻撃・術師は3回とも討ち尽くす
5. **遠攻撃の素が弱い。**骨の短弓の素は1体に毎秒40で、大剣(331)の1/8。1.6倍の目安を大きく超えて離れている(弓は装備で巻き返すが、それは原因Cのせい)
6. **耐久はどのビルドも頭打ち近くまで伸びる。**揃えると耐久1,500〜2,600(素の約5〜8倍)。被ダメージの下限は効いているが、最大HPが重なる
7. **雷雨は今も強い。**最初の巡礼者・雷雨の術師は傷の半分ほどが感電(濡れで倍・連鎖)。初期の相互作用は狙いどおり働いている

- 数値は `npm run sim` で出し直せる(3〜4分)。型は `packages/core/src/sim/archetypes.ts` に足せる

## 2回目:補正値をまとめ、繋ぎを厳しくした後

直したこと:装備の与ダメージと状態の蓄積の補正値を「全体・技の種類・属性・状態」の4つの種類にまとめた(同じ種類は足し算)。繋ぎは厳しいものほど倍率を上げ、種類と属性をまたぐ繋ぎは両方を変えないと決まらないようにした(種類→種類 ×2・+2、属性→属性 ×3・+3、種類と属性をまたぐ ×4・+4)。

わかったこと:

- **繋ぎは一辺倒のビルドで選ばれなくなった。**揃えた装備に入る繋ぎは9ビルドで合わせて2つ(前は16)。大剣の「近攻撃→斬」の常時×2.5は消えた
- **それでも装備で14〜40倍になる。**種類をまとめても、7部位の補正値の足し算そのものが大きい(属性+300%・全体+200%・種類+200% で ×36)。次の手は補正値の大きさを下げること(たいてい-20〜+60%)
- **弓・大盾の爆発は収まった。**弓 ×53→×27、大盾 ×171→×18
- **儀式は少し伸びた。**×2.9→×5.0(祭司の防具と、儀式を宿した技のダメージの補正値が入った)
- **大物の体力を160,000にした。**揃えたビルドの飛竜への毎秒の傷は800〜5,800(中央値は約1,400)。最初の巡礼者で約200秒、中央値で約110秒、大剣で約30秒。体力30,000では6〜35秒で倒れていた
- **近接は相変わらず群れを討ち尽くせない。**自動のステップ(下記)は操り手にはまだ使わせていない

## 3回目:近接にステップを使わせたとき(2026-10-29)

方針:補正値は大きいまま(キャラはインフレする)にし、敵をそれに合わせてインフレさせる。

操り手にもステップを使わせた(`npm run sim:step`)。当たりそうな弾と、満ちる直前の振りかぶりはステップで抜け(自分の技がもうすぐ出るなら潰さずに受ける)、離れた相手へはステップで詰める。装備は揃えたもの、3回ずつ。「討」は呼ばれた群れに対する倒した割合(呼び出された屍喰いも数えるので、霧の墓守りは100%を超える)、「受」は受けた傷、「踏」はステップの回数。

わかったこと:

- **ステップで受ける傷が大きく減る。**近接は1/3〜1/10になり、倒れる回数はほぼ0になった(大剣の夜 1,561→496、短剣 2,901→312、大盾 482→52)
- **討つ割合も上がるが、討ち尽くせない。**近接の夜は77%→86〜95%。それでも3回とも夜明けまで残る
- **近接が討ち尽くせないのは、操り手が慎重すぎるせい。**試しに「一番近い敵へまっすぐ詰め続ける」だけにすると、大剣は灰の街道の夜を69秒・倒れ0で討ち尽くした。射手や支援役は歩いて追えば追いつける。近接は「踏み込む覚悟」が要り、遠攻撃は安全に戦える、という差になっている(企画どおり)
- **大物にはステップが高くつく。**飛竜は絶えず振りかぶるので、操り手は2秒に1度ステップを踏み、そのたびに自分の振りかぶりを潰す。短剣・大盾・最初の巡礼者は、歩くだけなら倒せたのに、ステップでは時間内に倒せなかった。人なら踏む時を選べるが、「振りかぶりを潰す」代償は大物戦では重い
- **遠攻撃はステップで得をする。**弓・最初の巡礼者は受ける傷が減り、討つ速さは変わらない

## 5回目:遠距離の速射と、術師のコンボの伸び(2026-10-29)

直したこと:

- **遠距離は速射。**遠距離の武器の間隔を0.45倍、振りかぶりと硬直を0.6倍にし、1発の威力を0.55倍・蓄積を0.5倍にした(`WEAPON_KIND_PACE`・`WEAPON_KIND_POWER`)。状態の溜まる速さはほぼ据え置きで、当たる数が倍以上になる。当てたときの条件文・付与の追撃・繋ぎが多く出る
- **術師はコンボで伸びる。**杖は、コンボのヒットごとに「魔力の高まり」が1つ溜まり(30まで)、1つにつき術(magic のタグ)の与ダメージ+5%。8秒コンボがなければ消える(`WeaponTypeDef.comboGrowth`)。速射になった分、杖の弾ける威力は0.35→0.2に下げた
- 近接と遠距離の釣り合い(遠距離の2.2倍以上)は保っている

わかったこと:

- **術師は群れで大きく伸びた。**雷雨の術師の素・群れ 724→1,676、揃え・群れ 10,005→22,934。霧の墓守りも3回とも討ち尽くした(夜の傷の62%に魔力の高まりが乗る)
- **術師は大物に弱いまま。**飛竜1体では感電の連鎖が起きにくく、コンボが続かない(毎秒625、時間内に倒せない)。雨を呼べる間だけ伸びる
- **速射は「当てたときの効果」を持つビルドを伸ばす。**最初の巡礼者は「移ろう属性」が当たるたびに乗り、揃え・1体 730→2,570。飛竜を3回とも倒した(毎秒701→1,211)
- **当てたときの効果を持たない遠距離は伸びない。**骨の短弓は揃え・群れ 1,058→998 とほぼ同じ。弓の素は1体に毎秒44で、近接の1/10のまま
