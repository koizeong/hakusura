# 付録A 条件文の候補(200)

装備やパッシブスキルの補正値の1枠を使って入る条件文の候補。コストは補正値換算の暫定値で、装備1つの合計(-100%〜+100%)に含める。強い条件文ほどコストが高く、他の項目の取り分が減る。
