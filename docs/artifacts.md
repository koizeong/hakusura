# 付録B アーティファクトの候補(200)

効果が固定された装備の候補。ランダムな装備よりも、ルールそのものを変える効果を中心にしている。強い効果には代償を付け、他の部品と組み合わせて初めて活きるものを多くした。装着できる部位は未決。
